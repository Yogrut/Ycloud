# Ycloud Vue 前端

这是 Ycloud 的 Vue 3.5 候选前端。当前阶段已经迁移首页登录、共享主题、文件浏览操作闭环，以及管理后台鉴权、统一布局和全部五个管理页面：“账户与访问”、“登录安全”、“传输限制”、“文件夹锁”和“WebDAV”。文件浏览包括目录导航、搜索、排序、选择、文件夹锁解锁、预览跳转、管理员登录入口、退出、多文件顺序上传、新建目录、单文件下载、打包下载、重命名、移动、复制和永久删除。

桌面端右键菜单跟随指针，并区分文件、已选项目和列表空白区域；桌面文件列表支持从文件行或复选框开始方向式拖选，向下增加选中行、向上取消已选行，不绘制额外选择框，也不触发文字选择、图片拖拽或外部文件拖入上传。移动端不启用拖选，选中项目后显示横向操作面板。批量操作保留后端逐项原子语义，部分成功时展示失败项目明细。

候选管理后台位于 `/v2/admin/account`。未登录时使用现有管理员登录限流接口完成认证；账户页不回显真实密码，只用固定掩码表示已有凭据。未修改的密码不会进入请求，清空已有首页密码必须再次确认，修改管理员用户名或密码后按后端规则退出当前管理会话。

登录安全页位于 `/v2/admin/security`，按正常、错误与限制状态分区，支持 1、3、7、15、30 天或全部记录筛选，并以每页 10 条分页。每条正常记录都提供“封禁此 IP”，确认成功后切换到错误与限制分区核对状态；异常记录可清除失败次数和限制。限制按记录对应入口生效，操作由管理员 Cookie 会话授权并由后端原子持久化。

传输限制页位于 `/v2/admin/limits`，只开放单文件上传、打包源文件总大小和打包条目数量三个业务边界。GiB 输入在未修改时保留服务器原始字节值，修改后转换为安全整数；前端与后端共同校验范围。并发、密码队列、事务锁和磁盘安全余量不开放调整。

文件夹锁页位于 `/v2/admin/locks`，支持新建、编辑和确认删除。路径保存前统一格式；根目录、无效路径以及与已启用 WebDAV 重叠的父、当前或子目录由 Rust 后端拒绝。新密码至少 8 位，编辑掩码不作为密码发送；锁发生变化后后端撤销对应解锁令牌。

WebDAV 页位于 `/v2/admin/webdav`，支持挂载列表、新建、编辑、启停、只读/读写和确认删除。浏览器只接收密码存在状态；保留掩码不会修改密码，清空密码时必须同时停用挂载。启用挂载需要独立用户名和至少 12 位密码，路径不能与文件夹锁的父、当前或子目录重叠。删除配置不会删除磁盘文件，客户端继续使用 `/dav/{挂载名}` 和独立 Basic Auth。旧后台保留完整回退，并在候选环境中把五个管理入口全部导回 Vue 页面。

旧版内嵌前端仍是生产入口和完整回退方案；候选前端不会修改现有生产路由或部署方式。

## 本地运行

先在仓库根目录启动 Rust 服务（默认 `127.0.0.1:18473`），再执行：

```powershell
cd frontend
npm ci
npm run dev
```

访问 `http://127.0.0.1:5173/v2/`，认证后进入 `http://127.0.0.1:5173/v2/browse`；候选管理后台为 `http://127.0.0.1:5173/v2/admin/account`。开发代理只转发 Ycloud 的同源 API，不使用外部 CDN。

## 依赖策略

- `package.json` 使用精确版本，`package-lock.json` 必须提交，安装使用 `npm ci`。
- 每周 Dependabot 只提出分组更新；任何更新都必须通过 lint、测试、类型检查和生产构建后人工合并。
- Vue 运行时与构建、检查、测试工具分组升级，降低一次更新的影响范围。
- TypeScript 暂固定为 `6.0.3`。虽然 7.x 已发布，但 `typescript-eslint 8.67.0` 的正式兼容范围仍是 `<6.1.0`，在其上游完成支持前不越过该边界。
- 不使用 `latest`、不自动合并、不为追求版本号绕过 peer dependency 检查。
