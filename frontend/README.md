# Ycloud Vue 前端

这是 Ycloud 的 Vue 3.5 候选前端。当前阶段已经迁移首页登录、共享主题、文件浏览操作闭环，以及管理后台鉴权、统一布局、侧边导航和“账户与访问”设置。文件浏览包括目录导航、搜索、排序、选择、文件夹锁解锁、预览跳转、管理员登录入口、退出、多文件顺序上传、新建目录、单文件下载、打包下载、重命名、移动、复制和永久删除。

桌面端右键菜单跟随指针，并区分文件、已选项目和列表空白区域；桌面文件列表支持方向式拖选，向下增加选中行、向上取消已选行，不绘制额外选择框，也不触发文字选择或外部文件拖入上传。移动端不启用拖选，选中项目后显示横向操作面板。批量操作保留后端逐项原子语义，部分成功时展示失败项目明细。

候选管理后台位于 `/v2/admin/account`。未登录时使用现有管理员登录限流接口完成认证；账户页不回显真实密码，只用固定掩码表示已有凭据。未修改的密码不会进入请求，清空已有首页密码必须再次确认，修改管理员用户名或密码后按后端规则退出当前管理会话。登录安全、传输限制、文件夹锁和 WebDAV 仍使用旧后台，待后续阶段逐项迁移。

旧版内嵌前端仍是生产入口和完整回退方案；候选前端不会修改现有生产路由或部署方式。

## 本地运行

先在仓库根目录启动 Rust 服务（默认 `127.0.0.1:18473`），再执行：

```powershell
cd frontend
npm ci
npm run dev
```

访问 `http://127.0.0.1:5173/v2/`，认证后进入 `http://127.0.0.1:5173/v2/browse`；候选管理后台为 `http://127.0.0.1:5173/v2/admin/account`。开发代理只转发 Ycloud 的同源 API，不使用外部 CDN。

## 依赖策略

- `package.json` 使用精确版本，`package-lock.json` 必须提交，安装使用 `npm ci`。
- 每周 Dependabot 只提出分组更新；任何更新都必须通过 lint、测试、类型检查和生产构建后人工合并。
- Vue 运行时与构建、检查、测试工具分组升级，降低一次更新的影响范围。
- TypeScript 暂固定为 `6.0.3`。虽然 7.x 已发布，但 `typescript-eslint 8.67.0` 的正式兼容范围仍是 `<6.1.0`，在其上游完成支持前不越过该边界。
- 不使用 `latest`、不自动合并、不为追求版本号绕过 peer dependency 检查。
