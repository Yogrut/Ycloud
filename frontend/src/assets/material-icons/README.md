# Material Icon Theme assets

Source: [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme/tree/a7ffd480d308a153b95cf241999dbaaa58bf4992), version 5.39.0, commit `a7ffd480d308a153b95cf241999dbaaa58bf4992`.

Only the 40 icons used by Ycloud's file listing are included. The 38 named SVGs come from upstream `icons/`. `file.svg` and `folder.svg` use the paths from upstream `src/core/generator/fileGenerator.ts` and `folderGenerator.ts`, wrapped as in `shared/svg.ts`. These two default icons are generated by upstream and are not checked into its `icons/` directory.

Ycloud adapts the SVG fills to a more saturated palette for its light surfaces. Folders are golden yellow (`#f9a825`); images use teal (`#009688`), archives amber (`#f59e0b`), text documents blue (`#1976d2`), spreadsheets green (`#16a34a`), audio/PDF red (`#e53935`), and videos orange (`#f57c00`). Other file icons use corresponding stronger hues; the generic file is blue-gray (`#607d8b`) and disc images are violet (`#7c3aed`). Paths, cutouts and secondary details are preserved. No CSS tint, filter or theme-dependent opacity is applied. MSI and EXE still share upstream's program-window shape rather than a dedicated installer icon.

The original [MIT license](LICENSE) is retained here and its copyright and terms are also included in Ycloud's distributed `THIRD_PARTY_LICENSES.md`. No runtime CDN or additional npm dependency is required.

Mappings are maintained in `apps/browser/fileIcons.ts`. SVGs are imported as URLs using Vite's `?no-inline` asset handling and included in the existing compiled resource table. Adding a mapping affects appearance only, not preview support, permissions, or file operations.
